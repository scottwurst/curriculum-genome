# The Curriculum Genome (prototype)

An interactive prototype for the University of Chicago Law School's 125th anniversary, prepared by the D'Angelo Law Library.

**All data in this prototype is invented.** Course titles, faculty names, descriptions, enrollment, and tuition figures are mock data meant to show what the finished site could do. Only the five dated school events (1902, 1904, 1933, 1939, 1959) are real.

## What's here

- `index.html` is the entire site in one file. No build step, no dependencies beyond two Google Fonts, which fall back to system fonts when offline.

## Viewing it

- Online: the GitHub Pages address for this repository.
- Offline: download `index.html` and double-click it. Everything works without a connection.

## Before wider sharing

- Replace the shield placeholder in the maroon bar with an official logo from UChicago Creative.

- Remove the `noindex` tag in the page head only when the site is meant to be found by search engines.
