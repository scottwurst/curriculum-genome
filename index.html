        About the data

        How the genome is built, how much of it a librarian has checked, and how to use it in your own work.

        1. Gather every AnnouncementScans from Chicago Unbound and the library's print run, with gaps flagged where no copy has been located.
        2. Read the pagesOptical character recognition turns each scan into text, keeping a link to the exact page.
        3. Extract course recordsAn AI model pulls each course's title, instructor, credits, and description into a structured record.
        4. Librarian reviewEvery record is checked against the page image before it is marked verified. Unverified records are labeled as such.
        5. Subjects and lineageLibrary staff assign each course to a subject and link renamed courses to their successors, using a documented scheme.
        6. Publish and correctThe dataset is released openly, and anyone can report an error from any record.
